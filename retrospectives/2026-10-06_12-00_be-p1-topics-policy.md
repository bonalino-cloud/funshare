# Ретро: be/p1-topics-policy (задача 14а)

**Задача.** Пересмотр тем прожарки (решение Дениса 05.10): тело, здоровье как привычки, семья и деньги открыты на всех степенях; болезни, тяжёлые события, дети, национальность, религия, политика, ориентация закрыты. Идёт до H1 дорожки юмора, чтобы новые темы вошли в базу `taste/v1`.

**Как решали.** Исполнитель (sonnet) → доработка по длинному тире тем же исполнителем (решение Дениса 06.10: «реши оптимально») → карусель (opus) 9/9 → чек оркестратора (typecheck, lint, 1167 тестов, build, проверка бандла) → живой прогон `lizysssi` на трёх степенях.

**Решено:** да. PR #82.

**Ключевые решения.** Новые версии промптов (`analyze/v2`, `roast/v2`, `roast/moderator-v2`) вместо правки v1, выбор версии в одной точке `src/server/prompts/active.ts`. Длинное тире: механическая замена в выходе ломает фразы («Ты — бариста» → «Ты, бариста»), поэтому слой 4 режет как раньше, а лечится причина: писатель копировал тире из данных (образцы банка, крючки, досье), теперь данные приходят без тире. Оценочные слова про тело оставлены закрытыми на rare/medium — ждёт подтверждения Дениса.

**Что поймала карусель.** Корень «внук» резал «Внуково» (аэропорт — частая тема путешественников). Замена «--» ломала punycode-адреса. Нормализация давала запятую в начале строки. С открытием темы семьи — риск назвать близких по имени или нику без их согласия: в промптах только роль (мама, партнёр).

**Что поймал живой прогон.** `roast:try` берёт последнее досье из базы, а оно было v1: первый прогон проверял старое досье. После анализа v2 запреты досье сузились («семейный статус» больше не в запретах), появились шутки про мужа, вырезано тире — 0 (было 25–40 %), на выходе 15–18 шуток вместо 12–13.

**Что сделать лучше.** При смене версии промпта досье живой прогон начинать с пересчёта досье, а не с готового из базы. Скрипт `pnpm analyze:try` по аналогии с `roast:try` сэкономил бы время.

**Было → стало.** Темы были закрыты шире решения продукта, тире резало треть оплаченного выхода → темы по решению Дениса во всех слоях и документах, выход писателя почти без потерь.

**Открыто.** Ревью Сергея п. 3 `invariants.md`, FE 6 `fe/p1-topics-copy`. `redline` в банке шуток строже политики — перемарковка отдельной задачей. Оценочные слова про тело — решение Дениса.
