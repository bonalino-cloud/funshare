# Ретро: `be/p1-analyze-step` — досье прожарки (LLM-часть analyze)

**Задача.** Шаг `analyze` по roast-engine §3–§4: ProfileSnapshot → ProfileFacts → один вызов LLM со схемой → `PersonaProfile` с досье (`observations`, `warmFacts`, `signatureMoves`, `sensitiveEvents`), гардрейлы, промпт `v1`, запись в `personas`.

**Как решали.** Оркестратор → исполнитель (sonnet, цикл 5 ходов) → проверяльщик (opus, карусель 01–09) → чек оркестратора. Ветка от `dev` после слияния #47 (поля досье в контракте).

**Решено:** да по коду; `[x]` ждёт живого прогона с `ANTHROPIC_API_KEY` и `db:migrate` миграции `0002`.

**Ключевые решения.**
- AI SDK 7: `generateObject` убран, взят `generateText` + `Output.object` (проверено по `node_modules`, не по памяти).
- Мягкая схема для модели, строгий `PersonaProfile.parse` после постобработки: `id` наблюдений ставит код, `post:N` = индекс в `snapshot.posts`, цифры `fact:*` сверяются с ProfileFacts.
- `sensitiveEvents` не дописываются в `avoidTopics`, хелпер `forbiddenTopics` = объединение (решение контракта #47; roast-engine §4 п.4 сформулирован старым способом).
- Идемпотентность: уникальный индекс `(snapshot_id, prompt_version)`, чтение до вызова, upsert. Каскад от снимка → досье с `sensitiveEvents` живёт не дольше 30 дней сырья.
- Обложки уходят провайдеру по URL, наш сервер их не скачивает.

**Что поймала карусель.**
- Выдуманная статистика в `fact:stats:*` проходила по формату — теперь значение сверяется с ProfileFacts.
- `look` собирался из одного аватара без показанных модели фото → описание внешности выдумано; теперь `null`.
- `post:03` и `post:3` — разные ссылки; нормализовано.
- Лимит ответа 4096 токенов обрезал полное досье на кириллице → три провала и `internal`; поднят до 8192.
- PII из ответа модели (текст на фото) шёл в досье только через `sanitizeText`; теперь `cleanUntrusted`.

Исполнитель в цикле 5 ходов поймал свой же баг `(d+)` вместо `(\d+)` в регулярках.

**Что сделать лучше.**
- Оркестратору — сразу передавать исполнителю, что модель может выдумать цифры: сверка всех `fact:*`, а не только повторов, должна была быть в промпте задачи.
- Таймаут худшего случая ~270 с на проверке до оплаты — учесть в `be/p1-profile-check` (общий дедлайн шага).

**Было → стало.** Было: контракт досье без производителя. Стало: шаг, который делает досье с проверенными опорами и пишет его идемпотентно.
