# Ретро: be/p1-generations-api

**Задача.** План phase-1, п.6: `POST /api/generations` и `GET /api/generations/:id` — проверка профиля → заказ (`createOrder`, промокод, проба) → строка `queued` → запуск конвейера (заглушка).

**Как решали.** `/фаза-цикл`: исполнитель (sonnet) → карусель 9 шагов (opus) → чек оркестратора. Логика в `src/server/generations/` (handlers, repository, workflow-заглушка, deps), маршруты тонкие. Миграция `0005_generation_inputs`: `profile_check_id`, `tier`, `level`, `extra_facts`, `trial_generation_id` — входы шага `write`.

**Решено:** да (код и тесты); миграция на Neon не применена — `[x]` после прогона.

**Что поймала карусель.** GET при недоступной соли хэша отвечал 500, POST — 503: выровняли на 503 + тест. Остальное — вычеркнуто как перестраховка при текущих объёмах: окно «заказ создан, строка не записана» при убийстве процесса; двойной сбой `startWorkflow` + `markFailed` оставляет `queued`; повтор POST с кодом после потерянного ответа спишет код второй раз (лечится ключом идемпотентности — правка контракта).

**Что поймал исполнитель (цикл 5 ходов).** Ложнозелёный тест «без cookie» (дефолтный параметр подставлял токен); гонка двойного POST — вторая получает `free_used`; IDOR по `trialGenerationId` и `profileCheckId` закрыт.

**Что сделать лучше.** Параллельная сессия переключила основную папку на `contracts/error-codes` посреди работы исполнителя — код пришлось увести в worktree `Funshare-generations`. Вторую пишущую сессию сразу открывать в worktree (правило «Границы проектов»), а оркестратору — стартовать задачу в worktree, если в папке может работать кто-то ещё.

**Было → стало.** Генерацию нельзя было создать → есть API создания и опроса статуса, заказ и проба по одному пути, откат заказа при провале.

**Хвосты.** Номер миграции 0005 конфликтует с `0005_error_codes_request_tier` из `contracts/error-codes` — кто сливается вторым, перенумеровывает в 0006 и пересоздаёт снимок. После слияния `contracts/error-codes`: кривое тело и недоступный тариф → `invalid_request` / `tier_unavailable` вместо 400 `internal`. Сверщик заказов `free` без генерации — отдельная задача.
