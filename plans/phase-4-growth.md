# Фаза 4 — Рост (бэклог, уточняется после запуска)

- **Новые типы артефактов** на том же `PersonaProfile`: гороскоп, прошлая жизнь, роаст, совместимость двух профилей. BE: новый `kind` + промпт. FE: новый шаблон страницы. Контракт: `contracts/kind-<name>`.
- **Аккаунты** (Sign in with Vercel / Clerk через Marketplace): история своих артефактов, перенос `ownerToken`-артефактов в аккаунт.
- **Оплата**: бесплатно N генераций, дальше — пакеты (Stripe через Marketplace).
- **Форматы шаринга**: вертикальная картинка 9:16 для сторис, скачивание PNG.
- **Другие соцсети** как источник: TikTok, X, Telegram-канал. Шаг `scrape` получает адаптеры, всё после `PersonaProfile` не меняется.
