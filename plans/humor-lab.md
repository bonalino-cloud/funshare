## Как запустить круг

Новые шутки или методики → одно сообщение в основную сессию:

```
Обкатка вкуса. Новый материал: <шутки / файл>. Новые методики: <название — пара слов, что это>.
Гоняем в песочнице против текущей версии.
```

Дальше по шагам. Денис нужен только на шагах 3 и 5.

1. **Материал.** Сессия разбирает присланное: шутки → карточки с методикой, повторы и запрещённое — в отбраковку,
   новые методики → карточки методик (H2). Собирает пакет `taste/vN+1` против текущего. Отчёт Денису: принято / отбраковано / новые методики.
2. **Прогон.** Обе версии на эталоне в песочнице (тестовая БД, боевая не задета). Время и цена прогона — в отчёт.
3. **Слепая оценка — Денис и Сергей.** Шутки вперемешку, версия скрыта. Отметка «огонь / норм / мимо» + причина.
4. **Отчёт.** Версии раскрываются: доля «огня» по версиям, «обидно», «нет логики», цена профиля, лучшая методика, вердикт ворот.
5. **Выкатка — решение Дениса.** Пробная доля 10% → живое сравнение → 100% или откат одной командой.

До появления админки шаги 3–4 идут в таблице (CSV / Google-таблица) и текстом в чат — круг не ждёт экранов.

## Задача H9 и экраны

- [ ] H9. `be/humor-lab-api` — **API лаборатории для админки**
  - `src/app/api/admin/taste/*`: материал (загрузка, разбор, отбраковка), прогоны (статус, время, цена),
    слепая очередь шуток и запись отметок, отчёт и вердикт ворот, пробная доля (чтение / смена / откат).
  - Контракты — zod-схемы в `src/contracts/` (общая зона, ревью обоих).
  - Версия в слепой очереди не уходит на клиент до закрытия оценки.
  - Доступ только админам: вход в админку — отдельная задача, админки в проекте ещё нет.
  - Опирается на H3 (прогон), H4 (отметки, ворота), H6 (пробная доля). Делать после H6, до публичного запуска или сразу после.
  - Критерий: полный круг (материал → прогон → оценка → отчёт → доля) проходит через API без ручных скриптов.

- **FE / Сергей:** раздел «Лаборатория вкуса» в админке по макету — 5 шагов: материал, прогон, слепая оценка, отчёт, выкатка.
  Заменяет строку «экран отметок в админке вместо CSV». Задача Сергею — issue со ссылкой на макет, когда дойдём до H9.
