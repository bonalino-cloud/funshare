# Фаза 3 — Защита, аналитика, запуск

**Цель:** сервис можно открыть публично и не разориться на ботах.

## BE

- [ ] `be/p3-rate-limit` — лимит генераций на IP и устройство (Upstash), `rate_limited`
- [ ] `be/p3-botid` — Vercel BotID на `POST /api/generations`
- [ ] `be/p3-moderation` — проверка готового текста на запретные темы перед `ready`, при провале — перегенерация
- [ ] `be/p3-retention-cron` — ежедневная чистка сырых данных старше 30 дней
- [ ] `be/p3-cost-guard` — дневной бюджет на генерации: при превышении — пауза с понятным статусом
- [ ] `be/p3-metrics` — SQL-вьюхи или страница `/admin` с метриками из `business/INDEX.md`

## FE

- [ ] `fe/p3-polish` — финальный проход по отступам, типографике, микроанимациям, тёмной теме
- [ ] `fe/p3-a11y-perf` — доступность, Lighthouse, вес страницы артефакта
- [ ] `fe/p3-legal-pages` — «Как это работает», политика данных, запрос на удаление
- [ ] `fe/p3-analytics` — Vercel Web Analytics, воронка лендинг → генерация → шаринг
- [ ] `fe/p3-e2e` — Playwright: полный флоу на моках и смоук на превью

## Definition of Done

- [ ] 100 генераций подряд с одного IP не проходят
- [ ] Дашборд метрик показывает воронку
- [ ] Страницы с политикой данных опубликованы
- [ ] Прод-релиз, тег `v1.0.0`
