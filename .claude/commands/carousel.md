description: Прогнать карусель проверочных промптов по текущей фазе в этом окне
---

Фаза и её код уже загружены в этом окне (выше по диалогу). Прогони по ним
карусель проверочных промптов из папки carousel/prompts/.

Соблюдай строго:

1. Работай ТОЛЬКО в этом окне. Не создавай субагентов, не открывай отдельных
   сессий — вся память должна остаться в текущем контексте (после карусели
   я продолжу здесь: ретроспектива, коммит).

2. Иди по файлам carousel/prompts/ строго по порядку: 01.md, 02.md, 03.md …
   и так до последнего файла.

3. Для каждого шага:
   - Прочитай ровно ОДИН файл — текущий.
   - Выполни его содержимое ДОСЛОВНО, как очередную инструкцию по текущей фазе.
     Не перефразируй промпт, применяй ровно ту формулировку, что в файле.
   - НЕ читай следующий файл, пока полностью не завершил текущий шаг.
   - НЕ заглядывай вперёд: пока делаешь шаг N, ты не знаешь, что в шаге N+1.
     Действуй так, будто следующих промптов не существует.

4. Переходи к следующему шагу ВНЕ ЗАВИСИМОСТИ от результата предыдущего —
   без ветвлений, без вердиктов «продолжать ли», без пропусков. До последнего файла.

5. Перед ответом на каждый шаг ставь заголовок:
   === Шаг NN: <имя файла> ===

6. Промпты вида «применяй. Diff» — действительно вноси правки в код проекта
   и показывай diff. После последнего шага остановись и жди меня.
