# Funshare — дизайн-система

Закон для всех экранов и мини-лендингов. Живой стайлгайд — страница `/design`. Токены — `src/styles/globals.css`, шрифты — `src/styles/fonts.ts`, компоненты — `src/components/`.

Если словесное указание в задаче спорит с этим файлом — прав этот файл.

## Характер

Ночной фестиваль: тёмный холст, на нём сочные цветные блоки, как афиши на стене. Эмоционально, легко, насыщенно, с юмором. Рефы — афиша MERSHE (бенто из цветных карточек, зерно, стикеры-цветы, смайлы-ромашки) и сайт Jiva Fest (узкий капс, бегущие ленты, стрелки ↗, пламя).

## Акцент фичи

Каждая фича — свой мини-лендинг с **одним ведущим цветом**: `<main data-accent="violet">`. Он задаёт `bg-accent` / `text-on-accent`, цвет главного блока и CTA. Всё остальное общее: шрифты, радиусы, стикеры, сетка. Так фичи выглядят одной семьёй.

| Фича | `data-accent` |
|---|---|
| Досье | `sun` |
| Прогноз | `violet` |
| Роаст | `tomato` |
| Прошлая жизнь | `cobalt` |
| Совместимость | `mint` |

Новая фича берёт свободный цвет из палитры. Новые цвета не добавляем без правки этого файла.

Приём из рефа: в углах блока — мелкий капс `type-eyebrow` (дата, «Every Saturday»), в центре или внизу — огромный заголовок.

## Форма

- `rounded-card` 28 px — цветные блоки; `rounded-tile` 18 px — вложенные плитки; `rounded-chip` — кнопки, пилюли, инпуты.
- Прямых углов у блоков нет.
- `shadow-block` — мягкая глубокая тень блока на холсте; `shadow-sticker` — у стикеров; `shadow-pop` — жёсткий сдвиг 4 px для полей ввода.
- Зерно `grain` на всех цветных блоках (включено в `Block` по умолчанию).

## Композиция

- Экран = бенто из `Block` на тёмном холсте, зазор 16–20 px. Блоки разного размера, один главный (7 из 12 колонок).
- Стикер `Sticker` лежит на углу главного блока, наполовину выходя за край.
- Между секциями — `Marquee` (бегущая лента) или `FlameEdge` (пламя).
- Кликабельные строки и карточки — со стрелкой `ArrowUpRight`, при наведении она поворачивается.
- Мобильная версия в приоритете: блоки в одну колонку, декор не перекрывает текст (ромашка уходит в поток под кнопку).

| Компонент | Что это |

| `Daisy` | Маскот — ромашка с рожицей (`smile`, `wink`, `wow`) |
| `Squiggle` | Розовая змейка под словом |
| `Circled` | Слово, обведённое красным эллипсом от руки |
| `Marquee` | Бегущая лента узким капсом, лаймом по чёрному |
| `FlameEdge` | Край-пламя для перехода к футеру |

## Кнопки и поля

- `Button` — пилюля, капс, иконка в чёрном круге. `accent` — главный CTA на холсте; `ink` — CTA внутри блока цвета акцента (иначе сольётся); `paper` — второстепенная; `ghost` — третичная.
- `LinkInput` — главное поле сервиса: кремовое, крупное, с `@`, жёсткая тень. Ошибка — человеческим текстом под полем, цветом `tomato`.
- `Pill` — теги и статусы в цветах блоков.

## Движение

- Hover кнопок: подъём на 2 px и наклон −1° с пружиной `ease-bounce`.
- Стикер вращается (`animate-spin-slow`), маскот покачивается (`animate-wiggle`), лента бежит (`animate-marquee`).
- `prefers-reduced-motion` глушит всю анимацию глобально.

## Иллюстрации (GPT Image 2.5)

Картинки артефактов генерирует DAN по промптам; стиль задаёт этот раздел. Каждый промпт начинается с префикса:

```
Flat retro-cartoon illustration in a 90s street-festival poster style. Bold black outlines,
simple shapes, limited palette: cobalt blue #2152C4, tomato red #E0463B, sunflower yellow #F5D133,
mint teal #3FA58F, violet #7C4DFF, cream #F3EBDD. Risograph grain and subtle halftone texture.
Stylized characters with simplified faces, never photorealistic, never a real person's likeness.
Playful props: boomboxes, palm trees, cocktails, smiling daisies with cartoon faces.
Solid flat background in one palette color. No text, no letters, no logos.
```

Правила:
- Лица — только стилизованные. Фотореализм и сходство с реальным человеком запрещены (`business/INDEX.md`).
- Фон картинки — один цвет палитры, чтобы она ложилась в блок того же цвета без шва.
- Фото, если понадобится, — ч/б с жёстким контрастом, утилита `halftone`, поверх цветного блока (реф HIPHOP NIGHT).
