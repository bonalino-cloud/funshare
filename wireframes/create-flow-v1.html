Создание артефакта · wireframe v1

Мобильный первый. Прогресс-линия из 7 сегментов: Профиль → Факты → Тариф → Прожарка → Итог → Шутки → Готово. Лоудер и выбор шуток живут внутри шестого сегмента, шеринг внутри седьмого. Серое = плейсхолдер: цвет, шрифты и стикеры берутся из DESIGN.md на этапе вёрстки.

Карточка нажимается целиком. Выбрано 6: остальные затемняются и не нажимаются (снять выбор можно). Кнопка активна только при ровно 6. Счётчик закреплён внизу. В артефакт попадают ровно выбранные, в порядке выбора. Кандидатов 10 (Поджог) или 20 (Кострище, Пекло). Версия 2: перетаскивание для порядка, «заменить одну шутку».
