# Карусель проверочных промптов (Funshare)

9 промптов `prompts/01.md … 09.md` прогоняются по уже написанному коду в ОДНОМ контексте,
строго по одному, без заглядывания вперёд. Тексты применяются дословно.

Два способа запуска:

- `/carousel` — в текущем окне тем же агентом. Для разовой правки вне плана.
- `/фаза-цикл` — оркестратор запускает отдельного субагента-проверяльщика, который сам
  читает файлы по одному (см. `.claude/skills/фаза-цикл/SKILL.md`, §2).

Правила для любого способа:

1. Один файл за раз. Следующий не открывать, пока текущий шаг не закончен.
2. Идти дальше при любом результате шага — без пропусков и вердиктов «продолжать ли».
3. Заголовок каждого шага: `=== Шаг NN: <файл> ===`.
4. «Применяй. Diff» — реально править код и показывать diff.
5. После 09 — остановиться.
